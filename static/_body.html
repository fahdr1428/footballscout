Percentiles are against players in the same position group in this pool. Where a metric is one a scout wants low — errors, miscontrols, fouls — the percentile is already flipped, so a high number is always good.
Where the data comes from. FBref match statistics joined to Transfermarkt squad records through a curated 15,440-row player mapping, both mirrored by worldfootballR_data. Positions are Transfermarkt's, taken from an independent source rather than inferred from the same statistics the models read — so grouping players by position is not circular.
How similarity is calculated. Each player is a vector of his position group's metrics, standardised so every metric counts equally, and similarity is the cosine between two such vectors × 100. Nothing is hand-tuned: a 90% match means the two profiles point in nearly the same direction across all of them. Comparisons only ever happen inside a position group, because a centre-back and a winger share no meaningful axis.
What market value is. Transfermarkt's estimate for that season, in euros. It is not a fee anybody paid, and it is partly informed by the same public data shown here.
A static extract of a larger Streamlit platform, which adds recruitment search, squad analysis, archetype maps and a model-validation suite across five seasons and ten position groups.
